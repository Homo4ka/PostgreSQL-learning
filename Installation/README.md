*Команда **apt-get** выдаёт очень подробные технические логи и является крайне стабильным инструментов(который обычно не меняется из версии в версию).*
*Команда **apt** же является обёрткой для **apt-get**, что выводит краткие логи с красивой TUI графикой. Создана специально для упрощения жизни.*
*Команда **apt full-update** является крайне радикальной системой обновления(так, например, может снести пакеты, которые считает не нужными), поэтому мы обойдём эту команду стороной.*

# Установка
всё очень просто. Сначала нужно открыть терминал и ввести:
```Bash
sudo apt update
sudo apt upgrade -y
```

*Команад **sudo** является командой для обретения админских прав.*
*Команад **apt** является пакетным менеджером(или, проще, утилитой для установки пакетов(файлов программ)).*
*Команад **update скачивает список** доступных обновлений.*
*Команад **upgrade устанавливает** доступные обновления.*
*Команад **-y** является тегом для автоматического соглашения на все предложения(да-да, можно согласиться скачать вирус, но сейчас не об этои).*
*допускается возможность упростить и не вводить по отдельности. Для такого используется между двумя командами "и", которая обозначается символами "&&"*

После этого, нам нужно скачать саму postgreSQL. Это делается следующим образом:
```Bash 
sudo apt install postgresql postgresql-contrib
```

*команда **install** устанавливает вписанный вами пакет. **upgrade** используется только для уже скачанных пакетов обновлления, тем времен как **install** используется для установки новых пакетов иподтягиванию всех зависимостей. **Install**, так же, проверяет, установлен ли уж пакет, илин нет.Если пакет установлен, то идёт поиск новых версий и их установка.*

После установки, стоит проверить, как дела идут у нашей СУБД. Вводим:
```Bash
sudo systemctl status postgresql
```

*Команад **systemctl** используется для запуска служюы(сервиса)*
*Команда **status** используется для показа полной информации о службе*
*Команда **postgresql** является службой.*

Если не служба не активна, то вводим:
```Bash
sudo systemctl start postgresql
```

*Команда **start** запускает службу.*
*Чтобы выключить службу, нужно прописать команду **stop**.*

Если что-то пошло не так, то в термирнале выведется ошибка и инструкция к тому, как её решить. Если всё скачалось, то продолжаем.

Установка СУБД из официального репозитория. Но, сначала нужен ключ подписи GPG. Это, уже, требование для подтверждения подленности репозитория. Вводим:

```Bash
curl -fsSL https://www.postgresql.org/media/keys/ACCC4CF8.asc | sudo gpg --dearmor -o /usr/share/keyrings/postgresql-keyring.gpg
```

*Команда **curl** является утилитой для передачи данных с серверов или на них по различным протоколами(по типу HTTP, FTP, SFTP и т.д.)*
*Команда **-fsSL** является флагом, который расшифровывается:*
- *Команда **-f(fail)** не отрабатывать ошибки HTTP. Только выводить ошибки в терминал*
- *Команда **-s(silent)** тихий режим. Никаких логов, ошибках и т.д. Выводит только чистый результат.*
- *Команда **-S(show-error)** отобразить ошибки. Так как предыдущий флаг перекрывает этот аспект, то использование этого флага помагает вернуть ошибки в терминал. Используется в связки только с предыдущим флагом.*
- *Команда **-L(location)** следовать перенаправлениям. Всё, что редеректит на другие сайты и протоколы **curl** на и будет автоматически переходить*
*Команда **gpg --dearmor -o** как раз таки того, что и будетключом*

А теперь, время для скачивания самого репозитория postgreSQL. Запускаем следующюю команду:
```Bash
echo "deb [signed-by=/usr/share/keyrings/postgresql-keyring.gpg] http://apt.postgresql.org/pub/repos/apt/ bullseye-pgdg main" | sudo tee /etc/apt/sources.list.d/postgresql.list
```

*Команда **echo** выводим строчку с параметрами репозитория(что бы убедиться в правильности данных).*
- *Команда **deb** указывает, что репозиторий содержит файлы .deb(готовые пакеты).*
- *Команда **signed-by**. Помните, мы получали ключ GPG? Так вот, эта команда ведёт на него.*
- *Команда **https"//...** является url адрессом того, откуда скачиваем пакеты*
- *Команда **bullseye-pgdg main** является указанием того, для какой версии операционной системы берём пакеты(ветка репозитоия ОС)*
*Команда **|** является перенаправление на следующую команду.*
*Команда **sudo tee** записывает фйал posgresql.list. Таким образом, у нас есть файл, который стал системным и чуть позже вы поймёте зачем это нужно. К слову, обычным **?** не получилось бы, ведь ветка /etc/apt защищена, **sudo tee** работает от имени суперпользователя.*

После интеграции библиотеки слона, нам нужно обновить репозиторий системы(и да, теперь слон является непосредственной частью ОС). Вводим:
```Bash
sudo apt update
```

*Это действие нужно, так как **apt** ещё не знает какие пакеты и версии этих пакетов нужно установить. В худшем случае, мы скачаем старую версию слона из стандартного шаблона версий. Будет хорошо, если просто даст ошибку. Таким шагом, мы заставляем **apt** зайти в файл posgreqsl.list прочитать.*
*Ну и конечно, надо понимать, что без этого **apt** может попытаться скачать зависимости, которых уже нет. Мы же, до этого, провели установку так, чтобы всё было установлено*

Теперь, самое время установить СУБД. Так как при помощи предыдущей системы мы получили список всех обновлений для системы(в том числе и слона), то вводим:
```Bash
sudo apt install postgresql
```

Поздравляю, мы установили PostgreSQL! Всё, что остаётся, это настройка, но этого уже нет в домашнем задании. Всем удачки!
